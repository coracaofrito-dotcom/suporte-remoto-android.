Suporte Remoto Android

Aplicativo de suporte remoto com compartilhamento de tela autorizado.

Objetivo

- Criar convites por QR Code.
- Solicitar autorização do Android antes de capturar a tela.
- Transmitir a tela em tempo real para um atendente autorizado.
- Permitir que a pessoa encerre o compartilhamento a qualquer momento.

Requisitos técnicos

- Aplicativo Android nativo.
- MediaProjection para captura autorizada da tela.
- WebRTC para transmissão de áudio/vídeo ou tela.
- Servidor de sinalização para conectar os dois aparelhos.
- HTTPS e conexões seguras.

A captura de tela e a transmissão precisam ser implementadas e testadas antes de considerar o aplicativo funcional.
